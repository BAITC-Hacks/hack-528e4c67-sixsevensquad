# ОргКонтур — ИИ-агент анализа организационной структуры и функционала

MVP веб-сервиса, который сравнивает комплекты документов «до» и «после» реорганизации и показывает:

- сохранённые, созданные, преобразованные и упразднённые подразделения;
- карту перехода функций;
- возможные потери функций;
- риски конфликта интересов и независимости;
- подтверждающие пункты и цитаты из документов.

Сейчас анализ работает без ИИ — на регулярных выражениях, сходстве текста и экспертных правилах. Позже вместо или поверх этого слоя можно подключить LLM API.

## Стек

- Frontend: React, TypeScript, Vite
- Backend: FastAPI, Python
- Документы: PDF, DOCX, XLSX/XLSM, TXT, Markdown

## Быстрый запуск

### Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Swagger будет доступен по адресу `http://127.0.0.1:8000/docs`.

### Frontend

В отдельном терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Сценарий демонстрации

1. Нажать «Загрузить демо» или выбрать свои документы.
2. Нажать «Начать анализ».
3. Посмотреть вкладки «Структура», «Функции» и «Риски».
4. Раскрыть ссылки на подтверждающие пункты.
5. Скачать JSON-отчёт.

## Что добавить при подключении ИИ

1. Создать сервис `backend/app/ai_analyzer.py`.
2. Передавать в него извлечённые пункты документов, а не исходные бинарные файлы.
3. Возвращать данные в текущем формате ответа `/api/analyze`.
4. Сохранить анализ по правилам как проверку и резервный режим.

# Проверка объединённой версии — 23.09.2026

Объединён код из `hackalem-orgkontur.zip` с проектом `hack-528e4c67-sixsevensquad`. Сохранены текущие `.env`, зависимости frontend и backend, контрольные документы, оформление и настройка MongoDB Atlas. Отчёты о тестах из архива не выдаются за результаты наших проверок.

## Подтверждено на этом компьютере

- 47 автоматических тестов: парсеры, цитаты, неполное извлечение, некорректные сопоставления, бюджет, остановка, кэш, экспорт и хранение. В этих тестах OpenAI подменяется; MongoDB проверяется через mongomock.
- TypeScript/Vite: сборка успешна.
- Реальный OpenAI, контрольный комплект: реорганизация отдела, потеря страхового реестра, дубль проверки расходов и конфликт самопроверки найдены. Проверка источников пройдена, предупреждений нет. 3 функции до, 4 после, 16 фрагментов.
- Первый живой ответ пропустил конфликт. После передачи исходных цитат в проверку рисков повтор использовал четыре сохранённых ответа и обнаружил конфликт. Суммарно две попытки: 6 запросов, 5802 входных и 1591 выходной токен; оценка $0.004867. Это результат одного контрольного случая, не гарантия стабильности модели.

## Полные PDF и Atlas

Сквозная проверка редакций №8 и №9 выполняется через `scripts/verify_integration.py` с потолком $0.50. Итог будет зафиксирован после завершения. Ответы и расход сохраняются в Atlas; проект можно продолжить по его ID без повторной оплаты уже сохранённых запросов.

## Что не утверждается

- Семантическая точность всех выводов и полнота извлечения не доказаны; требуется ручная проверка.
- OCR, графические оргсхемы, внешние нормы и бенчмаркинг не проверялись и не реализованы.
- Браузерный сценарий перенесён как отдельный тест, но при объединении не запускался. Сборка frontend не заменяет визуальную проверку.
- Авторизация пользователей и публичное безопасное развёртывание не реализованы.

## Воспроизведение

```bash
backend/.venv/bin/pip install -r backend/requirements-dev.txt
backend/.venv/bin/python -m pytest -q backend/tests
cd frontend && npm run build && cd ..
# Платная проверка с текущим ключом, с кэшем и потолком $0.03:
backend/.venv/bin/python scripts/live_smoke.py --control
# Только при явном повторе после изменений, расход проекта не сбрасывается:
backend/.venv/bin/python scripts/live_smoke.py --control --refresh
```

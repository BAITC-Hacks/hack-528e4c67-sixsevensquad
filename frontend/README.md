# ОргКонтур — интерфейс

React + TypeScript + Vite. Использует существующий FastAPI через `/api`; серверный контракт не изменён. Стартовый экран — загрузка двух редакций, без встроенных демонстрационных результатов.

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

Фронтенд: http://127.0.0.1:3000. Vite перенаправляет `/api` на существующий сервис http://127.0.0.1:8000. Сборка: `npm run build`, просмотр сборки: `npm run preview -- --host 127.0.0.1`.

## Структура

- `src/hooks/useAnalysis.ts` — загрузка, выбор проекта, запуск анализа, опрос статуса, сохранение решений и восстановление проекта из URL.
- `src/components/AppShell.tsx` — навигация, логотип, состояние API и мобильное меню.
- `Documents.tsx` — выбор файлов, проверка форматов/размеров, библиотека и поиск исходных пунктов.
- `Comparison.tsx` — отдельное сопоставление каждой функции: владелец и формулировка до/после.
- `AnalysisOverview.tsx` — сводные показатели из результата API.
- `Results.tsx` — все выводы, реестр функций, структура, риски, заключение и серверные экспорты.
- `FindingDetails.tsx` — источники двух редакций, область поиска и сохранение решения с комментарием.
- `src/styles/` — базовые элементы, раскладка, документы, результаты, диалоги и анимации. Учитывается `prefers-reduced-motion`.

## Проверка интерфейса

Загрузить два файла или контрольный пример → запустить анализ существующего сервиса → проверить структуру, сравнение, реестр и риски → открыть источник → сохранить любой из трёх статусов с комментарием → открыть проект повторно → скачать заключение. OpenAI вызывается только сервером; при недоступности API или отсутствии настройки показывается фактическое состояние.
